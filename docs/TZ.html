8. Production uchun sizdan kerak

  • .env.production: TELEGRAM_BOT_TOKEN, TELEGRAM_BOT_USERNAME, TELEGRAM_WEBHOOK_SECRET (kompyuterdagi bilan boshqa), TELEGRAM_POLLING=false.
  • Deploy → npm run telegram:webhook -- https://<domen> → npm run telegram:check.
  • Kompyuterda polling ishlab tursa, u production webhook'ini o'chiradi — serverga chiqargach kompyuterda false qiling.
  • Click/Payme merchant kalitlari — backend/src/services/payments/ ga bitta provayder fayli.
  • Bot tokeni chatda bir marta ochilib qolgan edi — /revoke qilinganiga ishonch hosil qiling.
