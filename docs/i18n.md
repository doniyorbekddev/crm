# Interfeys tillari

Tillar: o'zbekcha (lotin, **manba**), o'zbekcha (kirill), ruscha, inglizcha. Tanlov — yuqori paneldagi til ro'yxati
(kirish sahifasida va kabinetda ham bor); brauzerda saqlanadi (`localStorage: crm.language`).

## Qanday ishlaydi

Koddagi barcha matnlar o'zbekcha (lotin) yozilgan va shunday qoladi. Boshqa til tanlanganda **tarjima qatlami**
(`frontend/src/i18n/`) ekrandagi matnlarni lug'at bo'yicha almashtiradi:

- `catalog/ru.json`, `catalog/en.json` — lug'atlar; kalit — o'zbekcha matnning o'zi. Ikki bo'lim: `exact` (to'liq matn)
  va `patterns` (o'zgaruvchili: `"{0} ta ochiq ish"`).
- `catalog/source.json` — ma'lum interfeys matnlari ro'yxati. Kirill shu ro'yxatdagi matnlarni algoritm bilan o'giradi
  (`transliterate.ts`), alohida lug'at yo'q.
- `domTranslator.ts` — sahifadagi matn tugunlari va `placeholder` / `title` / `aria-label` / `alt` atributlarini
  tarjima qiladi; React yangilagan matnni ham ushlaydi.

Muhim xususiyatlar:

- **Standart tilda (o'zbekcha) qatlam umuman ishlamaydi** va lug'atlar yuklanmaydi.
- **Lug'atda yo'q matn o'zgarmaydi.** Shu sababli foydalanuvchi ma'lumotlari (ism, guruh va kurs nomi, izoh, email)
  tarjima qilinmaydi va kirillga o'girilmaydi.
- Server xabarlari (toast, xato matnlari, bildirishnomalar) ham lug'atga kiritilgan.
- Tarjima qilinmasligi kerak bo'lgan joyga `data-no-translate` atributi qo'yiladi. `code`, `pre`, `kbd`, `textarea`
  ichi avtomatik chetlab o'tiladi.

## Yangi matn qo'shilganda

```bash
cd frontend
npm run i18n:check            # lug'atda yo'q matnlar ro'yxati (bo'lsa — chiqish kodi 1)
node scripts/i18n-check.mjs --write   # source.json ni yangilaydi (kirill darhol ishlaydi)
```

So'ng `ru.json` va `en.json` ga tarjimani qo'shing. Qo'shilmagan matn o'sha tillarda o'zbekcha ko'rinadi (xato emas).
Bo'laklardan yig'iladigan matnlar (`"5mln"`, `"jami 18"`) koddan avtomatik chiqmaydi — ular `catalog/manual.json` da.

## Cheklovlar

- Tarjimalar mashina yordamida tayyorlangan va tanlab ko'rib chiqilgan; ona tili sohibi tomonidan to'liq tekshirilmagan.
- Telegram bot matnlari, PDF/Excel eksportlari va email xabarlari tarjima qilinmagan (faqat veb-interfeys).
- Sana va oy nomlari formatlash funksiyalaridan chiqadi — ba'zilari o'zbekcha qoladi.
- Rus va ingliz tilida so'z tartibi bo'lak-bo'lak yig'ilgan jumlalarda ("3" + " ta saqlanmagan o'zgarish") g'alati chiqishi mumkin.
- Bitta so'zdan iborat foydalanuvchi matni tasodifan interfeys so'ziga teng bo'lsa (masalan guruh nomi "Bugun"), u ham tarjima bo'ladi.
